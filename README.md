# Draftloom

<img src="assets/logo.svg" width="64" alt="">

โปรแกรมเขียนแบบ 2 มิติที่ทำงาน **ในเบราว์เซอร์ของคุณทั้งหมด** — เปิด แก้ไข และบันทึกไฟล์ DXF ได้ ไม่มีไฟล์ถูกอัปโหลด ไม่ต้องติดตั้ง

**ใช้งานออนไลน์:** https://ronsuthlor3-lab.github.io/draftloom/
ลองเปิดไฟล์ตัวอย่าง [`samples/house-plan.dxf`](samples/house-plan.dxf) (แปลนบ้านพร้อมเส้นบอกขนาดและข้อความไทย)

## ทำอะไรได้บ้าง

| หมวด | ฟีเจอร์ |
|---|---|
| วาด | เส้นตรง, เส้นต่อเนื่อง, สี่เหลี่ยม, วงกลม, ส่วนโค้ง 3 จุด, ข้อความ (ไทยได้), เส้นบอกขนาด, วัดระยะ |
| แก้ไข | เลือก (คลิก / กรอบ / กรอบแตะ), ย้าย, คัดลอก, หมุน, ย่อ/ขยาย, สะท้อน, เส้นขนาน, ตัดเส้น, มนมุม, แตก, ลบ, ย้อนกลับ/ทำซ้ำ 100 ขั้น |
| ความแม่นยำ | ดูดจุด (ปลาย กึ่งกลาง ศูนย์กลาง ควอดรันต์ จุดตัด), กริด, ล็อกแนวตั้งฉาก, พิมพ์พิกัด |
| จัดการ | เลเยอร์ (สี ซ่อน ล็อก เปลี่ยนชื่อ), แผงคุณสมบัติแก้ค่าตัวเลขได้ ดูความยาว/พื้นที่ |
| ไฟล์ | เปิด/บันทึก **DXF**, บันทึกงาน `.json`, ส่งออก SVG / PNG, บันทึกอัตโนมัติในเบราว์เซอร์, ลากไฟล์มาวาง |

### การพิมพ์คำสั่งและพิกัด
พิมพ์ในช่องด้านล่างแล้วกด Enter (หรือ Space):

| พิมพ์ | ความหมาย |
|---|---|
| `เส้น` หรือ `line` / `l` | เริ่มคำสั่ง (ทุกคำสั่งมีชื่อไทยและอังกฤษ ดูในคำแนะนำของปุ่ม) |
| `10,20` | จุดที่พิกัด x=10, y=20 |
| `@50,0` | ห่างจากจุดล่าสุด 50 ทางขวา |
| `@100<30` | ห่าง 100 ที่มุม 30° |
| `250` | ห่าง 250 ตามทิศที่เมาส์ชี้ |
| Enter เปล่า | จบคำสั่ง / เรียกคำสั่งล่าสุดซ้ำ |
| Esc | ยกเลิก · Delete ลบที่เลือก · Ctrl+Z / Ctrl+Y · F3 ดูดจุด · F7 กริด · F8 ตั้งฉาก |

เมาส์: ล้อ = ซูมที่ตำแหน่งเมาส์ · ปุ่มกลางลาก = เลื่อน · คลิกขวา = Enter · จอสัมผัส: สองนิ้วซูม/เลื่อน

## เปิดไฟล์ DWG ได้ไหม
ยังไม่ได้ DWG เป็นรูปแบบปิด ให้บันทึกเป็น DXF จากโปรแกรมที่ใช้อยู่ (แทบทุกโปรแกรมเขียนแบบทำได้) หรือแปลงด้วยโปรแกรมแปลงไฟล์ฟรี แล้วเปิด DXF แทน

## วิธีรันเอง
เปิดผ่านเซิร์ฟเวอร์ในเครื่องใดก็ได้ เช่น `python -m http.server` แล้วเข้า `http://localhost:8000` หรือเปิด `index.html` ตรง ๆ ก็ได้ — **ไม่มีไลบรารีภายนอก** ใช้ออฟไลน์ได้

**สำรองข้อมูล:** บันทึกอัตโนมัติอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น ถ้าล้างข้อมูลเบราว์เซอร์จะหาย — กด "บันทึก DXF" หรือ "บันทึกงาน" เป็นระยะ

## แรงบันดาลใจและความแตกต่าง
แนวคิด "โปรแกรมเขียนแบบ 2 มิติที่สั่งงานด้วยคำสั่งพิมพ์และดูดจุด" ได้แรงบันดาลใจจาก AutoCAD (ใช้ชื่อเพื่ออ้างถึงเท่านั้น)

- โครงการนี้ **ไม่มีส่วนเกี่ยวข้อง ไม่ได้รับการรับรองหรือสนับสนุน** จาก Autodesk, Inc.; AutoCAD, DWG และ DXF อาจเป็นเครื่องหมายการค้าของ Autodesk
- เขียนใหม่ทั้งหมดจากสเปกเชิงหน้าที่ของเราเอง ([docs/spec.md](docs/spec.md)) **ไม่ได้ถอดโค้ด** ไม่มีโค้ด ข้อความ ไอคอน หน้าจอ หรือไฟล์ใด ๆ ของ AutoCAD
- การอ่าน/เขียน DXF เขียนเองจากเอกสารโครงสร้าง DXF ที่เผยแพร่สาธารณะ เพื่อให้ทำงานร่วมกับโปรแกรมอื่นได้

| | Draftloom | AutoCAD (ตามที่ทราบทั่วไป) |
|---|---|---|
| ชื่อ / โลโก้ / สี | Draftloom, วงเวียนบนกระดาษ, พื้นกระดาษอุ่น + หมึกเขียว | ของเจ้าของ |
| ที่รัน | เบราว์เซอร์ ไม่ต้องติดตั้ง | โปรแกรมเดสก์ท็อป / บริการของเจ้าของ |
| รูปแบบไฟล์หลัก | DXF (R12) และ JSON ของตัวเอง | DWG |
| ขอบเขต | 2 มิติพื้นฐาน | 2D/3D เต็มรูปแบบ |
| ไม่มีใน Draftloom | 3 มิติ, DWG, แรเงา, ชนิดเส้น, ความหนาเส้น, layout/พิมพ์ตามสเกล, บล็อกที่แก้ไขได้, สคริปต์ | — |
| สัญญาอนุญาต | MIT โอเพนซอร์ส | ซอฟต์แวร์เชิงพาณิชย์ |

## เครดิต
ไม่มีไลบรารี ฟอนต์ หรือไอคอนจากภายนอก — โค้ด ไอคอน (เส้น SVG ใน `app.js`) และโลโก้ (`assets/logo.svg`) ทำขึ้นเองทั้งหมด ใช้ฟอนต์ของระบบ

## ข้อจำกัดที่ทราบ
- เปิด DXF แล้วบันทึกกลับ: บล็อกถูกแตกเป็นวัตถุเดี่ยว, แรเงา (HATCH) ถูกข้าม, เส้นบอกขนาดถูกส่งออกเป็นเส้น + ข้อความ, ELLIPSE/SPLINE กลายเป็นเส้นต่อเนื่องประมาณค่า, ข้อความหลายบรรทัดแยกเป็นหลายบรรทัดเดี่ยว
- ไม่อ่าน DXF แบบไบนารี และไม่อ่าน DWG
- ตัดเส้นและมนมุมใช้กับเส้นต่อเนื่องไม่ได้โดยตรง (ใช้ "แตก" ก่อน)
- บล็อกที่ย่อขยายไม่เท่ากันในแกน X/Y ทำให้วงกลมในบล็อกผิดรูปเล็กน้อย
- ไฟล์ใหญ่หลายหมื่นวัตถุอาจหน่วง
- ทดสอบแล้วบน Chromium; Firefox/Safari ยังไม่ได้ทดสอบ (ดู [docs/test-report.md](docs/test-report.md))

### แผนภายหลัง
แรเงา, ชนิดเส้น/ความหนาเส้น, พิมพ์ PDF ตามมาตราส่วน, บล็อกที่แก้ไขได้, ยืด/ต่อเส้น (extend), อาร์เรย์, PWA ออฟไลน์, DWG (ต้องตัดสินใจเรื่องสัญญา GPL ของไลบรารีที่อ่านได้)
