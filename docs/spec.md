# สเปกเชิงหน้าที่ — Draftloom

> เขียนด้วยคำของเราเองจากความรู้ทั่วไปว่า "โปรแกรมเขียนแบบ 2 มิติ" ทำอะไร
> ไม่ได้ถอดโค้ด ไม่ได้คัดลอกข้อความ ไอคอน หรือหน้าจอของโปรแกรมใด
> รูปแบบไฟล์ DXF อ้างอิงจากเอกสารโครงสร้าง DXF ที่เผยแพร่สาธารณะ

## ผู้ใช้และเป้าหมาย
นักเรียน ช่าง ผู้รับเหมา หรือใครก็ได้ที่ต้อง **เปิดแบบ 2 มิติ (DXF) ดู แก้ไข และบันทึกกลับ** หรือเขียนแบบง่าย ๆ เอง ในเบราว์เซอร์ โดยไม่ต้องติดตั้งโปรแกรม และไม่อัปโหลดไฟล์ไปที่ใด

## ฟีเจอร์และเกณฑ์ยอมรับ

### วาด
| รหัส | ฟีเจอร์ | เกณฑ์ยอมรับ |
|---|---|---|
| F-01 | เส้นตรง | คลิกต่อเนื่องได้หลายเส้น, Enter จบ, `C` ปิดรูป |
| F-02 | เส้นต่อเนื่อง | ได้วัตถุเดียวหลายจุด, `C` ปิดรูป, `U` ถอยจุดล่าสุด |
| F-03 | สี่เหลี่ยม | สองมุมทแยง ได้เส้นต่อเนื่องปิด 4 จุด |
| F-04 | วงกลม | จุดศูนย์กลาง + คลิกหรือพิมพ์รัศมี |
| F-05 | ส่วนโค้ง | 3 จุด (เริ่ม ผ่าน ปลาย); 3 จุดอยู่แนวเดียวกันต้องแจ้งเตือน |
| F-06 | ข้อความ | คลิกจุดวาง แล้วพิมพ์ข้อความ รองรับภาษาไทย |
| F-07 | เส้นบอกขนาด | 2 จุดวัด + จุดวางเส้น แสดงความยาวอัตโนมัติ |
| F-08 | วัดระยะ | 2 จุด แสดงระยะ มุม ระยะ X/Y |

### ป้อนข้อมูลแม่นยำ
| รหัส | ฟีเจอร์ | เกณฑ์ยอมรับ |
|---|---|---|
| F-10 | ช่องคำสั่ง | พิมพ์ชื่อคำสั่ง (ไทยหรืออังกฤษ) แล้ว Enter; Enter เปล่าเรียกคำสั่งล่าสุดซ้ำ |
| F-11 | พิกัด | `x,y` สัมบูรณ์, `@dx,dy` สัมพัทธ์, `@ระยะ<มุม` เชิงขั้ว, ตัวเลขเดียว = ระยะตามทิศเมาส์ |
| F-12 | ดูดจุด | ปลาย กึ่งกลาง ศูนย์กลาง จุดควอดรันต์ จุดตัด พร้อมสัญลักษณ์บอกชนิด |
| F-13 | กริด / ตั้งฉาก | เปิดปิดได้ ล็อกจุดเข้ากริด / ล็อกแนวนอน-ตั้ง |

### แก้ไข
| รหัส | ฟีเจอร์ | เกณฑ์ยอมรับ |
|---|---|---|
| F-20 | เลือก | คลิก, ลากซ้าย→ขวา = ต้องอยู่ในกรอบทั้งชิ้น, ขวา→ซ้าย = แตะกรอบก็เลือก, Shift+คลิก เอาออก |
| F-21 | ย้าย / คัดลอก | จุดฐาน → ปลายทาง; คัดลอกวางซ้ำได้หลายครั้ง |
| F-22 | หมุน / ย่อขยาย | จุดฐาน + มุม (คลิกหรือพิมพ์) / ตัวคูณ |
| F-23 | สะท้อน | แกน 2 จุด เลือกเก็บหรือลบต้นฉบับ |
| F-24 | เส้นขนาน | ระยะ + วัตถุ + ด้าน ใช้กับเส้นตรง วงกลม ส่วนโค้ง เส้นต่อเนื่อง (ไม่มีส่วนโค้ง) |
| F-25 | ตัดเส้น | คลิกส่วนที่จะตัดทิ้ง โดยใช้วัตถุอื่นทั้งหมดเป็นขอบตัด (เส้นตรง ส่วนโค้ง วงกลม) |
| F-26 | มนมุม | สองเส้นตรง + รัศมี (0 = ต่อมุมแหลม) |
| F-27 | แตก / ลบ | เส้นต่อเนื่องและเส้นบอกขนาดแตกเป็นชิ้นย่อย; ลบด้วยปุ่มหรือ Delete |
| F-28 | ย้อนกลับ / ทำซ้ำ | อย่างน้อย 100 ขั้น, Ctrl+Z / Ctrl+Y |
| F-29 | คุณสมบัติ | แก้เลเยอร์ สี พิกัด รัศมี ข้อความ ความสูงตัวอักษร; ดูความยาวและพื้นที่ |
| F-30 | เลเยอร์ | เพิ่ม เปลี่ยนชื่อ สี ซ่อน ล็อก ตั้งเป็นปัจจุบัน ลบ (เมื่อว่าง) |

### ไฟล์และมุมมอง
| รหัส | ฟีเจอร์ | เกณฑ์ยอมรับ |
|---|---|---|
| F-40 | เปิด DXF | อ่าน LINE, CIRCLE, ARC, LWPOLYLINE/POLYLINE (รวมส่วนโค้ง), TEXT, MTEXT, ATTRIB, ELLIPSE, SPLINE, SOLID, LEADER, INSERT (บล็อก), DIMENSION; ข้ามพื้นที่กระดาษ; แจ้งจำนวนวัตถุที่ข้าม |
| F-41 | บันทึก DXF | ไฟล์ ASCII รุ่น R12 เปิดกลับในแอปนี้ได้ และเปิดในโปรแกรม CAD ทั่วไปได้ |
| F-42 | บันทึกงาน / เปิดงาน | ไฟล์ `.json` ของแอปเอง เก็บครบทุกอย่าง |
| F-43 | ส่งออก SVG / PNG | ภาพทั้งแบบ พื้นขาว |
| F-44 | บันทึกอัตโนมัติ | ปิดแล้วเปิดใหม่งานยังอยู่ (ในเบราว์เซอร์เครื่องเดิม) |
| F-45 | มุมมอง | ล้อเมาส์ซูมที่ตำแหน่งเมาส์, ปุ่มกลาง/เครื่องมือมือเลื่อน, สองนิ้วบนจอสัมผัส, ดูทั้งหมด |
| F-46 | ความเป็นส่วนตัว | ไม่ส่งไฟล์ออกจากเครื่อง |

## กฎ
- ไฟล์ DWG: แจ้งให้แปลงเป็น DXF ก่อน (ไม่อ่าน DWG ใน MVP)
- DXF ที่อ่านไม่ได้ / ไบนารี: แจ้งข้อความ ไม่ล่ม และไม่ทับงานเดิม
- วัตถุบนเลเยอร์ที่ล็อก: เลือกและแก้ไม่ได้ แต่ดูดจุดได้

## กรณีขอบ
ไฟล์ว่าง, ไฟล์ใหญ่หลายหมื่นวัตถุ, ข้อความไทยในไฟล์ DXF เก่า (codepage 874) และใหม่ (UTF-8), วัตถุซ้อนบล็อกหลายชั้น, ส่วนโค้งที่ถูกสะท้อน (extrusion −Z), รัศมีมนมุมใหญ่เกิน, เส้นขนานกันตอนมนมุม

## สิ่งที่ไม่ทำ (MVP)
สามมิติ, เปิด/บันทึก DWG, แรเงา (HATCH ถูกข้าม), ชนิดเส้นประ, ความหนาเส้น, พิมพ์ตามมาตราส่วน, layout/paper space, สคริปต์, ทำงานร่วมกันหลายคน
