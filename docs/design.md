# บันทึกการออกแบบ

## เอกลักษณ์
- **ชื่อ**: Draftloom (draft = แบบร่าง, loom = กี่ทอ) — พี่น้องกับ LeafLoom ไม่มีคำว่า "CAD" หรือชื่อสินค้าของผู้อื่น
  ชื่อสำรอง: Linewright, Plotfern, ร่างเส้น — ผู้ใช้ควรค้นฐานเครื่องหมายการค้าก่อนใช้จริง
- **โลโก้**: วงเวียนกับเส้นโค้งบนแผ่นกระดาษ วาดเป็น SVG เอง (`assets/logo.svg`)
- **สี**: พื้นกระดาษอุ่น `#fbf8f1` + หมึกเขียวเข้ม `#1f5f4a` + อำพันสำหรับสิ่งที่เลือก; โหมดมืดใช้พื้นเขียวเทาเข้ม
  (ตั้งใจไม่ใช้พื้นที่ทำงานสีดำ/เทาเข้มแบบโปรแกรม CAD ทั่วไปเป็นค่าเริ่มต้น)
- **ไอคอน**: วาดเองทั้งหมดเป็นเส้น SVG ขนาด 24 px ใน `app.js`
- **ข้อความ**: เขียนใหม่ภาษาไทยทั้งหมด
- **เลย์เอาต์**: แถบไฟล์ด้านบน, รายการเครื่องมือมีชื่อภาษาไทยด้านซ้าย, แผงคุณสมบัติ/เลเยอร์ด้านขวา, ช่องคำสั่ง + ปุ่มสถานะด้านล่าง
  เป็นเลย์เอาต์ทั่วไปของแอปวาดรูป ไม่มีริบบอนหรือแท็บแบบของโปรแกรมใด

## การป้อนคำสั่ง
ชื่อคำสั่งรับทั้งไทย (เช่น `เส้น`, `วงกลม`, `ย้าย`) และอังกฤษ (`line`, `circle`, `move`) พร้อมตัวย่อตัวอักษรต้นคำ
การใช้ตัวย่อ ปุ่ม F3/F7/F8 และรูปแบบพิกัด `@dx,dy` / `@d<a` เป็น **วิธีใช้งาน** ที่ผู้ใช้งานเขียนแบบคุ้นเคย
ซึ่งเป็นความคิด/วิธีการ ไม่ใช่การแสดงออก (พ.ร.บ.ลิขสิทธิ์ ม.6 วรรคสอง) — ไม่ได้คัดลอกข้อความช่วยเหลือหรือรายการเมนูของโปรแกรมใด

## สถาปัตยกรรม
- หน้าเดียว HTML/CSS/JS ไม่มีไลบรารีภายนอกเลย ไม่ต้อง build ใช้ออฟไลน์ได้หลังโหลดครั้งแรก
- โมเดลข้อมูล: `doc = { layers[], current, entities[], textH }`
  ชนิดวัตถุ: `line`, `poly` (จุด `[x, y, bulge]`), `circle`, `arc` (มุมเรเดียน ทวนเข็ม), `text`, `dim`
- เรขาคณิตทุกชนิดแตกเป็น "ชิ้นพื้นฐาน" 2 แบบ: ส่วนของเส้นตรง และส่วนโค้ง — ใช้ร่วมกันในการวาด เลือก ดูดจุด หาจุดตัด และตัดเส้น
- การแปลง (ย้าย หมุน ย่อขยาย สะท้อน บล็อก) ใช้เมทริกซ์ affine ตัวเดียว
- ย้อนกลับ = เก็บสำเนา JSON ของเอกสาร 100 ขั้น
- DXF: ตัวอ่านรองรับ UTF-8 และ codepage เก่า (`$DWGCODEPAGE`), escape `\U+XXXX`; ตัวเขียนออก R12 (AC1009) ASCII ล้วน
