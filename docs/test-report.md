# รายงานทดสอบ — 2026-11-10

ทดสอบในเบราว์เซอร์ฝังในแอป Claude (Chromium) ผ่าน localhost ทั้งด้วยสคริปต์ (พิมพ์คำสั่งในช่องคำสั่ง) และด้วยการคลิก/ลากเมาส์จริง

## มือถือ / การเข้าถึง
- 375 px: ไม่มีแถบเลื่อนแนวนอน; ปุ่มเครื่องมือสูง 48 px เลื่อนแนวนอนได้
- ทุกการวาดทำได้ด้วยคีย์บอร์ดล้วน (พิมพ์คำสั่งและพิกัด) — เป็นทางเลือกแทนการคลิก/ลาก
- ปุ่มทุกปุ่มมีชื่อ (aria-label/ข้อความ), มีกรอบโฟกัส, Esc ยกเลิก
- สีข้อความรองผ่าน AA (≈ 6:1)

## ยังไม่ได้ทดสอบ
- Firefox / Safari
- ไฟล์ DXF จริงจากโปรแกรม CAD เชิงพาณิชย์ขนาดใหญ่ และการเปิดไฟล์ที่บันทึกจาก Draftloom ในโปรแกรม CAD อื่น
- จอสัมผัสจริง (หยิกซูม)
