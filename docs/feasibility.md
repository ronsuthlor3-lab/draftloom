|---|---|---|

| เปิด/บันทึก DXF (F-40, F-41) | เบราว์เซอร์ล้วน | DXF เป็นข้อความ เอกสารโครงสร้างเผยแพร่สาธารณะ เขียนตัวอ่าน/ตัวเขียนเอง |

| เปิด DWG | ทำได้แต่ไม่ทำใน MVP | DWG เป็นรูปแบบปิด ไลบรารีเปิดที่อ่านได้ส่วนใหญ่เป็น GPL (ทำให้ทั้งแอปต้องเป็น GPL) หรือเป็นบริการเสียเงิน → ทางเลือกตอนนี้: ให้ผู้ใช้แปลง DWG → DXF ด้วยโปรแกรมแปลงไฟล์ฟรี |
| แรเงา, ชนิดเส้น, พิมพ์ตามมาตราส่วน | เบราว์เซอร์ล้วน | ภายหลัง |
| ทำงานร่วมกัน / คลาวด์ | ต้องมีเซิร์ฟเวอร์ | ภายหลัง |
| สามมิติ | เกินกำลัง MVP | |
| ถอดโค้ด / ใช้ไฟล์ของ AutoCAD | ทำไม่ได้/ไม่ควรทำ | ม.30 |

## MVP vs ภายหลัง
- **MVP**: F-01 – F-46
- **ภายหลัง**: DWG (ต้องตัดสินใจเรื่อง GPL), HATCH, linetype/lineweight, พิมพ์ PDF ตามมาตราส่วน, บล็อกที่แก้ไขได้ (ตอนนี้บล็อกถูกแตกเป็นวัตถุเดี่ยวตอนเปิด), PWA ออฟไลน์

## ความเสี่ยง
- ล้างข้อมูลเบราว์เซอร์ = งานที่ยังไม่บันทึกหาย → มีปุ่มบันทึก DXF/JSON และบันทึกอัตโนมัติ
- ไฟล์ DXF ใหญ่มาก (> 50,000 วัตถุ) อาจหน่วง
- เปิด DXF แล้วบันทึกกลับ: บล็อก, แรเงา, เส้นบอกขนาด (ส่งออกเป็นเส้น+ข้อความ), ชนิดเส้น จะไม่คงรูปแบบเดิม → แจ้งใน README
